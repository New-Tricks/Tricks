```bash
brew install new-tricks/tap/tricks
```

Your skills live in a **source repo**: a plain git repository with your own skills and customized copies of upstream ones. `tricks` works on that repository, from the first search to the published release.

```text
discover ─► create / vendor ─► edit on a branch ─► link & try with agents ─► merge ─► lint ─► publish
```
